# Store gallery

Real screenshots from Minecraft 26.2 (Fabric), taken with the mod's own screenshot mode
(`GEGI_SCREENSHOT`, see `DevScreenshot`). Upload them to each project's gallery with these
titles and descriptions.

## 01-playing.png (featured)

**Title:** A web game, running inside Minecraft

**Description:** Open Doctrines playing in Minecraft's own window. Keyboard, mouse and scrolling go to the game; press Esc twice to leave, or open it in your browser.

## 02-menu.png

**Title:** The GEGI menu

**Description:** Recommended picks, live shelves from itch.io, a search box, and a box for pasting any itch.io or Newgrounds link. Open it from Options, with /gegi, or from your mod list.
